Eco-Rush
Cómo funciona
Eco-Rush es un videojuego móvil en 2D tipo "endless runner" con un enfoque de concientización ambiental. 
El jugador controla a un buzo que navega por el fondo del océano con una misión clara: recolectar la mayor cantidad de basura marina posible para sumar puntos. 
Durante el trayecto continuo, el jugador debe esquivar diversas piedras y obstáculos; chocar contra ellos reduce la barra de vida del personaje. 
Para añadir variedad a la experiencia, el sistema permite intercambiar entre 3 personajes jugables distintos.

Visualmente, el juego destaca por el uso del efecto Parallax, sobreponiendo múltiples capas de imágenes de fondo que se mueven a diferentes velocidades para crear una ilusión de profundidad tridimensional mientras el buzo avanza.

Tecnologías
Entorno de Desarrollo: Android Studio.

Lenguaje de Programación: Java.

Técnicas Visuales: Lógica algorítmica para Parallax Background Scrolling (sobreposición y desplazamiento de capas de imágenes).
